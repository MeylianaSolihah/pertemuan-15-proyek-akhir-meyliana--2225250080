# Proyek Akhir Alpro 15
## Program Rekap dan Analisis Nilai Matematika Kelas

### Deskripsi
Program Python untuk membaca data nilai siswa, memvalidasi input,
menghitung statistik nilai, menentukan ketuntasan berdasarkan KKM,
dan menyimpan laporan hasil analisis.

### Fitur
- Membaca data siswa dari file teks.
- Memvalidasi nama dan nilai siswa.
- Menerima nilai dalam rentang 0 sampai 100.
- Menghitung rata-rata, nilai tertinggi, dan nilai terendah.
- Menghitung jumlah siswa tuntas dan belum tuntas.
- Menampilkan dan menyimpan laporan hasil analisis.
- Menangani file yang tidak ditemukan dan data tidak valid.
